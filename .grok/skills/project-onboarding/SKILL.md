# Project Onboarding Skill

When activated or when the user starts a session / asks for status:

1. Read `AGENTS.md` and any `PRODUCT.md` or `docs/` files.
2. List key directories (`data/`, `src/`, `notebooks/`, `docs/`) and summarize what exists.
3. Identify the current highest-priority goal from conversation history or files.
4. Propose the next 1–3 concrete actions and which agents would own them.
5. Ask the user one clarifying question if the goal is ambiguous.

Keep the response short and actionable. This skill exists to reduce context-rebuilding cost for the Product Owner agent.
